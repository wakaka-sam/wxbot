# 快捷命令

微信或网页发送独立 `/xxx` 消息即可使用。命令由平台直接处理，不调用模型；帮助、状态与任务查询不会中断正在进行的回复。未连接微信时，网页仍可使用命令，普通聊天和附件上传仍需连接微信。

| 命令 | 用途与示例 |
| --- | --- |
| `/guide` | 分步创建待办、提醒、收藏和通知设置，预览后确认 |
| `/todo today` | 查看今日及逾期待办；`/todo add 2h high 提交方案` 新建 |
| `/save link URL 标题` | 收藏链接，也支持 message 消息编号 / file 附件ID |
| `/collection unread` | 稍后读列表；show/read/unread/tags/delete 管理，网页可导出 |
| `/help` | 列出命令；`/help task` 查看具体参数 |
| `/status` | 当前连接、运行状态、等待作业、投递数量、微信回复剩余额度 |
| `/settings` | 只读查看当前模型、默认时区、任务/附件限制、超时与工具失败阈值；别名 `/config` |
| `/whoami` | 当前用户名、角色和助手名称，不展示凭据 |
| `/tasks [页码]` | 每页 5 个任务，未结束任务优先；别名 `/schedule` |
| `/task ID` | 查看任务详情、规则、正文与下次执行时间 |
| `/task ID history [游标]` | 最近 3 次执行及微信投递状态；下一页使用返回的游标 |
| `/task ID pause` | 暂停规则并取消未开始的该规则作业 |
| `/task ID resume` | 恢复暂停的规则 |
| `/task ID cancel` | 取消规则，不能恢复；已运行作业可继续完成 |
| `/task ID run` | 立即真实执行并投递，原计划不变；会实际执行任务中的外部操作 |
| `/remind 30m 该喝水了` | 30 分钟后直接发送正文；也支持 `2h`、`1d`、`30分钟` |
| `/remind daily 09:00 吃早餐` | 每天北京时间 09:00 提醒 |
| `/remind workdays 10:00 休息` | 周一至周五提醒，不判断法定节假日 |
| `/remind every 2h 起身活动` | 每 2 小时提醒 |
| `/remind at 2027-01-01T09:00:00+08:00 新年计划` | 在包含时区的 ISO 时间提醒 |
| `/search 关键词` | 搜索自己的历史，使用 `/message 编号` 查看原文 |
| `/notify` | 查看通知偏好，支持免打扰、最终回复和任务摘要 |
| `/memory` | 查看记忆，`add 内容` 添加，`delete ID` 删除快捷记忆 |
| `/templates` | 列出模板；`/template morning preview 09:00 科技动态` 预览，改为 create 创建 |
| `/stop` | 请求停止当前执行，取消当前已排队作业；保留会话、文件和周期规则 |

任务 ID 可复制 `/tasks` 返回的完整 ID，或至少 8 位的唯一前缀；只能查询或操作自己的任务，管理员也不能借命令跨用户操作。分页参数、未知命令和不支持的参数会明确提示，不交给模型猜测。

`/remind` 只创建轻量提醒，正文原样发送；需要查询、总结或执行操作时，请在网页任务面板选择智能任务，或用自然语言创建。微信离线时任务等待连接，额度不足时结果在投递队列等待。`sent` 表示微信接口接受，不表示用户已读。`/status` 的剩余额度是该回复发送前的快照；网页命令不增加微信额度。

网页输入 `/` 会显示命令菜单，或点击输入框中的 `/` 按钮。方向键选择、Tab 填入、Enter 发送、Escape 关闭；也可直接点击命令。普通聊天中的 `/status`、代码块和 `/workspace/file` 等多层路径不会作为命令执行。要把独立的斜杠文本交给模型，使用双斜杠，如 `//status`。

命令必须单独发送，附带附件时只保留消息并提示，不执行命令。命令回复保存在网页历史；微信发起的命令另外经原有投递队列返回微信，网页发起的命令只在网页回复，避免重复通知。普通网页聊天继续同步到微信。

## 持久化与验收

除需要跨文件系统操作的快捷记忆外，输入、任务修改、命令回执及微信 outbox 在同一 SQLite 事务中提交。嵌套任务事务使用 savepoint；任何存储故障都回滚整次命令。相同来源消息 ID 或网页 requestId 重放只返回已存回执，不再次创建/运行任务，也不再次停止后续的新回复。升级前已经摄入的斜杠消息不会被重新当作命令执行。

命令不经 shell，也不接受助手 ID、微信接收人或模型凭据参数；唯一任务前缀只在当前助手的任务中解析。

验证：`node --test test/platform/commands.test.js` 和 `node scripts/test-platform-commands-browser.mjs`，配合完整平台测试和原有网页浏览器回归。

搜索、通知、快捷记忆和模板的完整规则与示例见 [工作空间工具](WORKSPACE-TOOLS.md)。快捷记忆使用持久化操作意图与版本检查恢复跨文件系统重试。
