# 待办、收藏箱和操作向导

在网页侧栏打开「我的待办」「收藏箱」「操作向导」，或直接发送下列命令。查询和管理命令不调用模型，也不打断当前回复；未连接微信时仍可在网页使用。

## 待办

- `/todo`：未完成列表；`/todo today`：今天到期和已逾期的未完成事项（北京时间）。
- `/todo add 2h high 提交方案`：两小时后到期、高优先级。时间支持 `30m`、`2h`、`1d`、含时区 ISO 时间；`none` 不设截止。优先级为 `high`、`normal`、`low`。
- `/todo edit ID title 修改后的标题`、`/todo edit ID due 1d`、`/todo edit ID priority normal`。
- `/todo done ID`：完成；`/todo delete ID`：删除。已完成记录不能重新开启，需要时新建。
- `/todo done-list`、`/todo all`；列表后可加页码，每页 10 条，ID 支持至少 8 位唯一前缀。

也可自然语言说：“记一条待办，下周五下午六点前提交方案，优先级高。”助手会通过持久化工具创建，可在网页或 `/todo` 核实。若日期有歧义，需要先明确时间。纯提醒仍使用原自动任务，不会同时创建两份提醒。

有截止时间的待办到点提醒一次，服务每 10 秒检查；重启不会重复创建通知。微信未绑定时等待绑定；离线、未收到首条微信输入、回复额度不足或免打扰期间等待投递。待办提醒不合并到任务摘要，保证完成/修改/删除时可以取消对应的积压通知。已进入发送中的通知或已发送通知无法撤回。修改截止时间会按新时间提醒；仅改标题或优先级不会重复已发送的提醒，尚未发送的旧正文会被替换。

每位用户最多保存 1000 条待办，截止时间须在未来一年内；列表按优先级、截止时间排序。无截止事项显示在普通未完成列表，不属于今日待办。

## 收藏箱

- `/save link https://example.com/article 参考文章`：保存链接和标题。
- `/save message 123`：保存消息正文快照和附件引用；消息编号可从历史搜索获得。网页消息或历史详情中的「收藏」可直接保存。
- `/save file 附件ID 文件标题`：收藏本人的已有消息附件。自然语言可要求“收藏刚才的文件”，助手先查询自己的近期消息获取附件 ID。
- `/collection`、`/collection unread`、`/collection read-list`：列表，可追加页码。
- `/collection show ID`、`/collection read ID`、`/collection unread ID`、`/collection delete ID`。
- `/collection tags ID 工作,参考`：替换标签；省略标签清空。每条最多 10 个标签，每个 30 字。
- `/collection search 关键词`、`/collection tag 工作`：搜索标题/正文或精确标签。更多筛选结果可在网页翻页。

网页支持创建、编辑标题/标签、搜索筛选、已读管理和导出全部 JSON，每位用户最多 1000 条。链接保存地址，不抓取网页正文；消息保存当时正文，文件保留已有附件引用，不另做备份。导出包含正文、标签和附件元数据，不包含附件文件内容。删除收藏不会删除原消息或附件。

## 操作向导

发送 `/guide`，按提示回复 `/guide 1` 等选择；也可点击网页「操作向导」。可分步新建待办、轻量提醒、链接收藏，以及设置通知偏好。

所有字段填写后展示预览，只有发送本次 `/guide confirm 确认码` 才提交。`/guide back` 返回修改，`/guide cancel` 退出，`/guide start` 重开。旧预览确认码失效，重复投递同一确认消息不重复创建。普通聊天不会被向导拦截；步骤均通过 `/guide 内容` 回答，独立数字或普通文字继续作为聊天。

向导状态按用户和来源渠道隔离，30 分钟未操作过期，服务重启可恢复未过期步骤。预览中的截止时间在确认时重新校验，过期不会偷偷改成其他时间。命令保留空行，避免微信把条目挤在一起。

## 实现与校验

待办、收藏、向导状态及写操作去重回执存于平台 SQLite 的 `todos`、`collections`、`guide_sessions`、`organizer_receipts`。迁移只新增表和索引，不改动历史消息和账号。与命令回执同事务提交；修改接口需要稳定 `requestId`，内容变更不得复用该标识。所有查询和写入按当前账号隔离，管理员也不能借个人管理接口跨用户访问。

自然语言使用每轮安装校验的 `wxbot-organize` 沙箱命令，通过带本轮 UUID 的文件中继调用宿主；无宿主 API 凭据，结束或中断的轮次不能写入。自动执行的任务仅能读取待办/收藏，不能自行创建或修改。每轮追加工具提示，因此恢复的旧会话同样可用。`wxbot-organize --help` 提供字段和示例。

测试：`node --test test/platform/organizer.test.js`、`node scripts/test-platform-organizer-browser.mjs`。隔离真实模型测试 `PLATFORM_AGENT_TEST=1 node scripts/test-platform-organizer-agent.mjs` 使用合成账号和模拟微信，不发送真实微信；可通过 `PLATFORM_LEGACY_HARNESS` 指向旧版本执行器，验证同一旧线程升级。

部署前在 sg 本地备份 SQLite，保持单进程轮询，空闲时升级。回退代码会停用这些入口和待办检查，但应保留新表，不能恢复旧备份覆盖升级后产生的消息。已生成的待办 outbox 应在回退前处理，避免旧版本失去待办完成校验后发送过期通知。
