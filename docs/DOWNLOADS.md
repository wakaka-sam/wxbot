# 附件失败后的备用下载

微信 CDN 重试耗尽、发送接口拒绝或发送结果未知时，发布原文件的临时下载链接，随后通过当前绑定发送文字通知。不会因为生成链接而重发媒体消息。下载使用独立随机 256 位令牌，24 小时后拒绝访问；后台每十分钟清理过期文件。令牌链接具有文件读取权限，无需注册登录，请仅分享给预期收件人。

SG 平台设置 `PLATFORM_PUBLIC_URL=https://wxbot.wakaka007.cn` 即可为本平台附件提供链接；副本和索引位于平台数据目录的 `downloads/`，不依赖助手工作目录或微信 CDN。下载始终使用 attachment 响应，不内联执行文件；链接不包含账号、目录和文件名。平台正常登录下载 API 的权限保持不变。

独立的旧消息台使用同一 SG 下载服务：

- 两端配置 `WXBOT_DOWNLOAD_TOKEN_FILE`，指向包含同一随机 64 位十六进制发布密钥的文件，目录 0700、文件 0600。
- 旧消息台另设 `WXBOT_DOWNLOAD_URL=https://wxbot.wakaka007.cn`。
- 发布接口 `POST /internal/downloads` 需要宿主 Bearer 凭据，接收不超过 20 MB 的原始文件及 `X-File-Name`（URI 编码）、`X-Download-Id`（64 位十六进制幂等标识）。该凭据不得提供给助手或浏览器；客户端不会跟随重定向。
- 公共下载仅支持 `GET/HEAD /downloads/<令牌>`，允许从微信等外站打开。其他接口继续保留同源及登录检查。

链接发布失败时保留原发送失败结果；不会生成无法验证的链接。文字通知本身也可能因微信不可用而失败。平台链接通知使用持久 outbox 和同一微信回复额度，重启后续发；旧消息台使用持久幂等回执防止重复通知。链接有效期从发布起算，长时间积压可能导致用户收到时已过期，此时需重新请求发送文件。

发布副本并非迁移账号、聊天历史或微信凭据；旧消息台仅在附件失败时上传该待交付文件。发布记录和凭据禁止提交 Git。关闭或回滚服务时保留 downloads 数据，直至已发出的链接失效。
